## 每个动作

- **短挥手**：右臂从身体侧面往上举起，到顶不停，小臂竖直、掌心朝前左右挥 3 下，再从侧面放回。来源：挥手位置取自录制 rec_20261109_145503；抬手、挥手、放手按关键姿态重新生成（原录制的挥手是肘部往外甩，不是左右摆）。
- **邀请**：右臂从侧面抬到侧前方、掌心朝上（“这边请”），停 1 秒后原路放回。来源：侧抬点和邀请姿态取自录制 rec_20261109_145516（0.85 s、1.36 s），邀请姿态肘部张开到 -0.85 rad 并加外展补高度。
- **自我介绍**：左臂从侧面抬起，手收到左胸前停 1 秒，退回时先回正手腕再从侧面放下。来源：侧抬点和胸前姿态取自录制 rec_20261109_145538（0.9 s、1.8~2.5 s 平均），肘部从限位 -2.34 退到 -2.2。
- **讲解**：双臂抬起向两侧摊开，停顿后放回。来源：录制 rec_20261109_145606，去掉断流卡顿帧后平滑，分阶段加速（保留录制的速度形状）。

## 接入要点

1. **手部单位是 rad，直接下发。** `hands.units="rad"`，按 2026-11-07 和同事对齐的约定。`hands.positions` 直接填入 URS 的 `hand_pos`（`hand_sub_mode=2`），运行时的 loader 要接受 `rad`。
2. **`hand_pos` 是 20 个值，先左后右。** 张手只在“动的那只手”上，另一只手全程保持初始姿态。
3. **进入要限速过渡。** 回放时手臂按 0.5 rad/s、最短 1.5 秒过渡到首帧。
4. **退出保持末帧。** 末帧就是站立默认姿态。
5. **切到 `STAND_DEFAULT` 时平台会让手握拳。** 手部过渡要从实测姿态开始。
6. **切 `UPPERBODY_REMOTE_SPLIT` 要按名字**（`action_desc`），`McAction` 里没有它的枚举值。
