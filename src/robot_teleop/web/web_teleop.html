IB手机遥操

使用说明

  1. 优先使用 AR：需要浏览器支持 WebXR；不支持时请使用摄像头光流模式。
  2. 光流仅作降级：不支持 AR 时再使用，适合低速、小范围临时调整。
  3. 握持姿势：左手握持手机，顶端朝夹爪/前方，屏幕朝右侧。
  4. 授权并连接：允许系统姿态传感器和摄像头权限，确认手机与机器人在同一局域网。
  5. 网络安全：仅限受信内部网络，禁止公网映射、云隧道、访客 Wi-Fi 和不可信 VPN。
  6. 开始操控：按住底部使能区移动手机；平移控制末端位置，旋转控制末端姿态。
  7. 常用操作：夹爪用张开/闭合；需要重新建立控制基准时点重新标定；需要回安全位点 Home。
