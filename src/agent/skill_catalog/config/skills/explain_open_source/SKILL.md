# explain_open_source

Say with a recorded reply that the software is open source and runs on many robot bodies.

- executor: `runtime_play_audio` (delegated); the catalog binds the logical clip name `open_source` (recordings `Q13` in `commissioning/audio/summit_clips.yaml`).
- recordings: 嗯嗯，软件是开源的，可以下载，装到很多机器人上哦！ / 开源的呀，下载下来能运行在很多机器人上～
- clip only, no gesture: a short answer with a gesture would leave the arms moving after the words.
- list the skill in `voice_bridge.silent_skills`: the clip is the reply.
- aliases: 你开源吗 / 别人能用你的代码吗 / 代码开源吗 / 能装到别的机器人上吗.
