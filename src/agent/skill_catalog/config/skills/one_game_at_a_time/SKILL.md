# one_game_at_a_time

Tell with a recorded reply that the visitor picks one game this round.

- executor: `runtime_play_audio` (delegated); the catalog binds the logical clip name `one_game_at_a_time` (recordings `W06` in `commissioning/audio/summit_clips.yaml`).
- recordings: 都想玩呀？这轮先选一个嘛～ / 嘿嘿，一次玩一个，先挑哪个？
- clip only, no gesture: a short answer with a gesture would leave the arms moving after the words.
- list the skill in `voice_bridge.silent_skills`: the clip is the reply.
- aliases: 两个都想玩 / 模仿和水果都要 / 两个游戏都要 / 我都想玩.
