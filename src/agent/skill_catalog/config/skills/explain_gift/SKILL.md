# explain_gift

Say with a recorded reply that the gift is hidden inside the fruit.

- executor: `runtime_play_audio` (delegated); the catalog binds the logical clip name `gift_what` (recordings `Q04` in `commissioning/audio/summit_clips.yaml`).
- recordings: 嘘，礼物藏在水果里哦！ / 每个水果里都藏着礼物哦！ / 嘿嘿，礼物在水果里，打开就知道啦！ / 是盲盒哦，礼物藏在水果里！
- clip only, no gesture: a short answer with a gesture would leave the arms moving after the words.
- list the skill in `voice_bridge.silent_skills`: the clip is the reply.
- aliases: 礼物是什么 / 你送的是什么 / 里面有什么 / 你到底送了什么东西 / 礼物就是水果吗.
