# robot-skill-web

本地 Web 控制台复用 `robot_client`。
启动时按部署配置绑定唯一目标，页面不发现、不选择、不切换机器人。
浏览器通过同源 HTTP 适配层访问客户端。
浏览器不直接连接 ROS 2 或厂商 SDK。
Gateway 保留运动授权、实时准入和执行账本。

## 启动

前置条件：本机已部署 `robot_config`，且与机器人侧 Gateway 使用同一配置。
本机和机器人已配置相同的受信 ROS 2 通信范围。
Web 启动时只读本地配置，不扫描 ROS 图、不连接 Gateway、不发送动作。
Web 启动时不加载密钥文件，也不读取本地凭证文件。
标准流程不输入密码、密钥或令牌。

1. 加载工作区环境。
2. 核对与 Gateway 一致的 ROS 域和受管 DDS 配置。
3. 用与 CLI 相同的规则选择部署配置并启动 Web 控制台。

配置解析顺序与 `robot-skill` 一致：
`--config-path` > `--config-name` > `ROBOT_CONFIG` > `ROBOT_NAME`。

启动绑定只读取部署配置公开的 `embodied` 传输契约（endpoint、robot 身份、timeout），
不要求 `runtime.interface_description` 快照、不编译本地技能、不读取模型目录，也不启动
runtime provider。页面上的状态、技能目录和执行数据全部来自 Gateway；因此
`--config-name unitree_g1_arm_presets` 或 `ROBOT_CONFIG=unitree_g1_arm_presets` 可以
直接启动 Web。`--config-path` 用于带部署 endpoint 覆盖的稳定文件，不需要复制
`/tmp/ibrobot_interfaces_*/robot.yaml` 运行期快照。
四者都没有时，Web 以退出码 2 报错，不启动服务，也不连接任何机器人。

```bash
source .shrc_local &&
ros2 run robot_skill_web robot-skill-web --config-name unitree_g1
```

服务只监听 `127.0.0.1`，默认端口为 `8765`。
终端显示绑定结果和访问地址。

1. 打开终端显示的地址。
2. 页面自动建立浏览器会话；连接栏显示已绑定的机器人。
3. 选择技能、准备并确认计划。

会话建立只设置浏览器 Cookie，不访问 Gateway。
状态、技能、任务查询和执行接口都使用该会话。
连接成功不代表运动已获授权。

控制面或技能目录不可达时，任务查询仍有独立入口。

### 会话与目标

警告：本流程依赖受信 ROS 网络。
`ROS_DOMAIN_ID` 不是安全边界，也不是认证。
网络内进程可能发送请求。
禁止把 Web 服务开放到公网。

目标在启动时固定：接口不接受 `candidate_id`、instance ID 或 ROS 端点。
换目标要重启 Web 并传入另一个部署配置。
页面没有「切换机器人」或「断开连接」入口。
浏览器会话有效期为 8 小时，过期后刷新页面即可重新建立同类会话。
重新建立会话会替换浏览器访问，但不会改变目标、取消任务或重发任务。

`POST /api/session` 只接受空对象；旧登录字段（`deployment_key`、
`startup_code`、`caller_token` 等）会被拒绝。
`GET /api/session` 只返回会话状态、公开目标标识和未确认任务引用。
目标的 endpoint、Robot 身份和当前 ROS 环境共同决定请求目标，浏览器不能覆盖。

若本机存档中还有属于其他部署的未确认任务，`POST /api/session` 返回 409，
需要先在对应部署上核对任务；连续被拒绝会触发 60 秒的会话建立限制。

会话 Cookie 和跨站请求伪造（CSRF）令牌自动管理。
Web 重启后仍是启动配置绑定的同一目标，不会重新发现。

## 凭证边界

标准 Web 和 CLI 使用受信 ROS 图，不使用凭证文件。
调用方作用域由部署配置决定，浏览器不能覆盖。
目标标识是路由身份，不是密码学认证。

宇树 G1 的 Web 操作和历史验证记录见[启动与操作归档](../../../docs/unitree_g1_operation_commands.md)。
旧临时部署目录已清理，禁止复活该目录。

## 执行与恢复

技能列表优先显示服务端提供的名称，不在浏览器维护动作名称表。
每行只显示名称、标签和就绪状态。
完整名称、技能标识和简介可在悬停提示或选中后的详情中查看。
技能列表在固定高度内滚动，不再随技能数量撑长页面。
选择技能时，列表保留滚动位置。
更改搜索内容后，列表回到顶部。

「预置」显示为独立标签，由服务端的 `tags` 字段决定。
名称和标签不改变执行标识、参数或运动授权。
未提供显示名称时，界面使用原始技能标识。
搜索支持显示名称、原始技能标识和简介。

宇树预置技能在列表中额外显示 `ID99` 形式的动作编号，详情显示
「宇树动作ID：99」。该编号来自服务端 `tags` 里的
`<vendor>_action_id_<N>` 展示标签（由运行时 profile 的
`vendor.arm_actions` 派生），不是列表序号、请求 ID 或工作流步骤，也不提供
执行入口。`release_arm` 另显示「控制权操作」标签，与普通「预置」区分；该
标签只是展示，不授予执行权限，也不会自动执行、恢复或收尾。非宇树技能不显示
动作编号。纯数字搜索按动作编号精确匹配（`99` 只匹配 99，`9` 不匹配 99），
不会匹配简介里的无关数字。

1. 选择技能并填写参数。界面自动填写执行说明，可按需修改。
2. 界面自动准备计划；修改参数或说明后，会在停止输入片刻后重新准备。
3. 检查展示的目标、步骤、参数、目录身份和预算。
4. 点击「执行 <技能名>」。只有这个操作会提交动作。

自动准备计划不会执行机器人动作。计划展示完成且运动已授权后，执行按钮才可用。
切换技能、会话或修改输入时，旧计划立即失效；迟到的响应不会恢复旧计划。
参数不完整时，界面等待补全，不会弹出校验窗口或提交动作。
准备失败时可以点击「重新准备计划」，不会自动循环重试。
执行中或结果未知时，禁止准备新任务；任务结束后需要重新选择技能，不能自动重复动作。

执行说明记录本次请求的目的，用于审计，不是动作参数。
默认内容为「通过 Web 请求执行技能：<技能名>」。
显示名称与技能标识不同时，默认说明保留名称和括号内的技能标识。

切换技能时，界面更新自动填写的说明，保留手工修改的说明。
清空说明后，自动准备计划时会恢复默认内容。
重新建立浏览器会话时，界面清空原说明。
填写说明不代表运动授权，也不代表动作已执行。

提交引用在发送前写入私有状态目录。
重复点击同一预览不会重复发送执行请求。
刷新页面会恢复执行引用，不重放动作。
存在活动或未知任务时，后端禁止新的提交。
目录不可用时，查询和取消不加载技能目录。

警告：「请求取消」不是硬件急停。

页面关闭、会话过期或后端退出不会自动取消任务。
只有服务端账本能确认执行终态。
状态文件损坏时，后端拒绝新的执行操作。
管理员必须核对原任务，不能靠删除记录绕过保护。

## 执行侧栏与历史命令

宽屏采用 3 列：技能列表、操作区、执行侧栏。
「执行与观察」显示当前任务，保留「请求取消」按钮。
窄屏将侧栏放到操作区下方。
历史列表和详情在各自区域内滚动。

工作台右上角的「收起侧栏」隐藏执行详情和历史区域。
宽屏收起后，技能列表和操作区使用腾出的空间。
「展开侧栏」恢复原内容，不清空计划或历史详情。
收起时，顶部仍显示当前执行状态和可用的取消入口。
折叠只改变页面布局，不提交动作，也不停止任务观测。

建立会话后，「历史命令」读取本机 Web 的提交记录。
列表按提交时间倒序显示最近 100 条记录。
记录包含技能名称、执行说明、参数和最后观测结果。
点击记录只查看保存的详情，不会重放动作。
查看历史不会改变当前任务或取消请求的目标。
任务提交和观测到终态后，界面自动刷新列表。

后端按机器人标识、调用方作用域和部署目标筛选历史。
同一目标的历史记录可跨 Web 重启保留。
详情显示部署标识，避免把旧结果当作实时状态。
记录保存在 `$XDG_STATE_HOME/ibrobot/robot-skill-web`。
默认路径是 `~/.local/state/ibrobot/robot-skill-web`。
刷新页面或重启 Web 不会删除记录。

其他部署写入的记录不会出现在当前目标的列表中。
目标标识变化（部署配置或 ROS 作用域变化）后，旧作用域的记录不迁移到新目标，
也不会被自动执行或重放。
历史只覆盖本机 Web 提交的命令，不包含 CLI 或其他客户端的命令。
仅准备计划、尚未点击执行的操作不会写入历史。
旧记录缺少技能名称、说明或参数时，界面明确提示缺失。
「未确认终态」不代表任务成功，也不代表机器人已停止。

`GET /api/history` 返回列表，`GET /api/history/<preview_id>` 返回详情。
这两个接口要求已建立的浏览器会话，只读取本地存档。
历史查询不会访问 Gateway、更新准入状态或自动执行动作。
详细事件最多保留最近 100 条，并受存档大小上限约束。
超长参数省略，事件截断或缺失时，界面显示提示。
历史存档不替代 Gateway 的权威执行账本。

### 历史接口返回 HTTP 404

升级代码后，浏览器可能加载新版页面，但 Web 进程仍运行旧版 Python 后端。
此时侧栏已显示，旧后端却没有历史接口。只刷新页面不会重新加载后端代码。

1. 确认没有活动任务或结果未知的任务。
2. 在 Web 所在终端按 `Ctrl+C`，只退出 Web 进程。
3. 在同终端使用原部署配置，重新运行
   `ros2 run robot_skill_web robot-skill-web --config-name <name> --port 8765`。
4. 刷新页面，再查看「历史命令」。

无需重启 Gateway 或机器人。禁止删除状态目录来处理此错误。

## 安全与范围

- 会话建立被拒绝达到 5 次后，限制 60 秒。
- 只保留 1 个有效浏览器会话，不改变任务状态。
- 会话 Cookie 使用 `HttpOnly` 和 `SameSite=Strict`。
- 变更请求核对 Host、Origin 和 CSRF 令牌。
- 接口限制 JSON 大小、嵌套深度和允许字段。
- 目标只来自服务器启动时的部署配置，浏览器不能指定 ROS 端点或候选实例。
- Web 标准流程不提交操作员身份凭证。
- 浏览器不能覆盖执行请求的授权作用域。

首版支持现有 WorkflowStep 契约内的单技能表单。
界面拒绝不支持的参数类型。
现有目录与发现链没有可信的逐技能真机验证结论，界面不伪造「已验证」或「未验证」逐技能标记。
工作台常驻说明「就绪」只表示 Gateway 当前报告该能力就绪，不代表已完成真机验收。
执行准入仍由 Gateway 判断；本机 mock 验证不能替代真实机器人验收。
