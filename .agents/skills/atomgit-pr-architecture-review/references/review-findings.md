# 架构评审发现格式

Agent 直接生成供人类审查的 Markdown，不再需要旧 `arch_issues.json` 发布协议。
每条发现包含：严重性、具体标题、所属维度、文件/行号证据、违反的既有契约、影响及修复建议。

维度：`ssot`（配置唯一来源）、`contract`（接口/数据契约）、`control`（控制模式）、
`package`（包职责）、`docs`（README 与实现）、`reuse`（复用与重复流程）。

严重性取 critical/error/warning/suggestion；结构偏好本身不能冒充 Bug。
摘要附方案对比和未覆盖范围。正文末尾标注 `🤖 generated by ai@<真实模型名>`。
具体结果经人类确认、源仓库/head SHA 复核后，用 CLI 发表；共享命令与定位规则见
[通用评论说明](../../atomgit-pr-review/references/api-and-issues-format.md)。
