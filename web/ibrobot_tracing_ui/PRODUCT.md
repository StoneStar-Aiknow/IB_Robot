# IB-Robot Trace 产品上下文

用户是排查机器人推理、调度和跨机器链路的工程师，包括第一次使用本工具的人与熟练分析者。主要在桌面和笔记本使用，同时需要小窗口/窄屏可达的核心操作。

核心任务：打开真实 trace 文件，找到值得调查的请求，解释耗时与来源，查看原始证据，返回继续分析，或对比另一份实验数据。

首次使用的前置任务：了解如何在业务机器上抓取 trace、可选添加 Python 埋点，并将完整文件交给 Web 服务读取。首页提供可见入口，完整指南与页首帮助共用；阅读后可返回原分析上下文。

成功标准：用户知道当前数据范围、计时起终点和下一步；操作可恢复，标准键盘行为可靠，不用记住内部页面规则。点击次数是辅助指标，不以隐藏信息换取表面简洁。

主路径为概览、请求分析、实验对比。拓扑、聚合与原始记录是上下文工具，按需展开，保留快捷键和深链接。

产品名称与首页标题为 **IB-Robot Trace**。界面统一用“trace 文件”指代数据文件；左上角图标和名称共同作为返回首页的链接。

事实约束：仅展示真实后端数据；墙钟不是CPU时间；Flow不等于纯网络；缺失、错误、不完整和有效零不同；未知主机/校准信息明确显示；数值可比不等于实验条件相同。

中文界面，Vue 3 / Pinia / Vue Router，复用现有分析API和组件。没有增加机器人控制操作或改变trace计算算法。
