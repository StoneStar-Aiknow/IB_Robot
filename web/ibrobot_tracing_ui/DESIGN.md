# Tracing 工作台设计约束

模式为 **Operate**。保留现有蓝灰工程工具视觉：主色 `--oe-primary`、中性面板、标准控件、等宽测量数字。优先可扫读、一致性和真实任务，保留合理数据密度。

## 结构

- 未载入时呈现“IB-Robot Trace”标题、trace 文件选择和明确开始动作；左上角品牌链接返回首页。
- 主导航为概览、请求分析、实验对比；更多视图提供原始记录、数据质量、全部调用聚合和拓扑。
- 每个视图显示实际作用范围。局部过滤、拓扑过滤与完整ID查找明确区分。
- 单请求详情保留请求身份、返回路径和相邻请求操作。拓扑可折叠，偏好仅存浏览器。
- 记录详情先摘要，再原始字段；窄屏在同一工作区显示详情，关闭后恢复原记录位置。

## 信息与状态

- 关键数字旁提供边界和单位。跨页来源/精度不同时不伪装成同一个数值。
- 区分未载入、加载中、过滤无匹配、无观测、错误、旧结果；图失败不保留带新范围标签的旧值。
- 请求/原始表真实分页；服务端名称查询覆盖当前范围全数据，本页文字过滤明确标注。
- trace 文件信息缺失显示未提供；不根据Web服务器或组件名称推断主机。

## 交互与可访问性

- 原生按钮和表单，Enter/Space等价；表格快捷键不截获交互子控件。
- 焦点使用清晰outline，适配forced-colors；关闭详情恢复合理焦点。
- 功能文字保持至少4.5:1对比度，状态不只靠颜色；减少动态效果时保留箭头/文本含义。
- 长ID可换行或完整查看，宽数据表在局部滚动，不造成根页面横向溢出。
- 任务导航形成浏览器历史，输入微调替换当前URL；失效分析有明确恢复路径。
- 浮层优先处理Esc并恢复触发器焦点；页签拥有自身方向键焦点，任务跳转才移动到标题或记录。
- 时间线标尺、条带与滚动容器共用时间域；组件范围变化需解释归因分母，文字过滤不重算时间轴。
- 颜色角色集中于 `src/theme.css`；图形和图例使用同一令牌，图表组件色稳定映射。粗指针下主要控件至少44px，宽表以局部滚动保留完整数值和单位。
- 归因片段与原始记录使用不同计时标签，并提供精确证据跳转；数据表保留原生行列语义，操作置于单元格按钮。
- 比较结论只描述观测差值及阈值，不推断实验条件一致或因果关系；结果ID可重开，待执行控件不覆盖结果原参数。
- 帮助按实际任务组织并可搜索，搜索状态与分析过滤隔离；技术名称保留，常用统计词和已知边界提供中文说明。
- 次级导航按记录/分析布局分组；计时摘要先给决策所需数值，详细边界与归因组成就地展开。
- 窄屏输入与清除/完成同行；完成编辑收起工具但保留筛选值。等待可退出，文案明确页面等待与后台任务的区别。
- 无匹配反馈独立于宽数据布局；摘要与分布优先四项数值，其他统计/定义可展开。短窗口的次级导航可滚出阅读区，紧凑请求栏保留返回和身份。
- 缓存结果删除是共享证据操作：确认后才发送，成功后才移出；失败保留结果与链接。结果参数始终可读，不与待执行参数混用。
- 目录/来源读取错误有命名恢复动作；已知诊断提供中文含义和精确请求链接，未知诊断保留原文。高对比度刻度和窄屏图例不能依赖默认渲染碰巧可读。

## 验证

使用真实 trace 文件验证主路径及双源对比，用受控API失败验证恢复。桌面、笔记本、窄屏及键盘均需检查。自动检测命中需人工复核，不能为清零删除语义状态标记或把工程表格改成展示卡片。
